## 📌 Project Overview & Objective
This repository contains the completed frontend web development tasks for Week 1. The objective of these projects is to demonstrate clean semantic HTML5 structure, modern CSS3 layouts (Flexbox & Grid), responsive design across desktop and mobile devices, and interactive UI components.

---

## 🛠️ Tech Stack Used
* **HTML5:** Semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
* **CSS3:** Flexbox, CSS Grid, Media Queries, Custom Variables, Transitions & Keyframe Animations
* **JavaScript:** Light DOM manipulation and form interactivity
* **Hosting:** GitHub Pages

## ✨ Key Features Implemented
1. **Professional Portfolio Website:** Multi-page responsive design featuring a hero banner, about section, skills showcase, project cards, and a functional contact form.
2. **Business Landing Page:** Brand-consistent responsive layout with navigation bar, value-proposition hero section, service cards, and validated contact form.
3. **CSS Challenge:** Responsive 3-card Flexbox row, 6-item CSS Grid gallery, and smooth hover/keyframe animations.
